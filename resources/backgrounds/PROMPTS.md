# 背景设计

通过 Codex 内置 `image_gen.imagegen` 生成，参考项目的沃雅妮莎头像；两张均为静态 PNG。以下是生成提示摘要。

- `moon-garden.png`：月下水庭。1536×1024 横向动漫插画，沃雅妮莎的青色长发、白色花饰与水元素服饰，半身角色位于右侧四分之一；月光、水庭、银白花纹、淡蓝雾气。左侧大面积明亮留白，为翻译输入与中文输出留出空间。没有文字、标志或水印。
- `morning-ripple.png`：晨光涟漪。1536×1024 横向动漫插画，沃雅妮莎的 Q 版形象坐在右下方睡莲上；薄荷绿、浅金晨光、白花和轻盈水波。与月下水庭采用不同构图、光线及角色表现，候选文字区域低对比、清晰可读。没有文字、标志或水印。

界面按比例填充并靠右下裁切；文字使用浅色卡片保持可读。角色权利归 miHoYo / HoYoverse，见 `THIRD_PARTY.md`。
