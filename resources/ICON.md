# PinyinShift 角色图标

`pinyinshift.png` 使用 Codex 内置 `image_gen.imagegen` 生成，`app.ico` 由 `generate-icon.ps1` 按 16、20、24、32、48、64、128、256 像素转换，保留透明背景与完整构图。

提示摘要：参考原神沃雅妮沙（沃雅妮莎）的青色长发、蓝色眼睛、双侧白花和水元素服饰；创作透明背景的 Q 版全身形象，从头到双脚完整可见。一只手开心挥手，另一只手轻提飘带，屈膝迈出轻盈舞步。轮廓清晰，适合小尺寸托盘图标；无文字、标志、水印或场景。
