# PinyinShift 角色图标

`pinyinshift.png` 使用 Codex 内置 `image_gen.imagegen` 生成，`app.ico` 由 `generate-icon.ps1` 按 16、20、24、32、48、64、128、256 像素转换，保留透明背景与完整构图。

提示摘要：以现有月下水庭背景作为身份与成熟画风参考，保留沃雅妮沙（沃雅妮莎）的青色长发、蓝色眼睛、双侧白花与青白水元素服饰。创作透明背景的完整全身角色，采用约 6.5 头身的成年比例、优雅安静的站姿、克制的微笑，一只手自然收在腰侧，另一只手放松；衣裙与长发轻轻展开。简化细节并保持清晰轮廓，以适配 16、20、24、32 像素托盘图标；不使用 Q 版大头、夸张表情、挥手跳跃动作，无文字、标志、水印或场景。两个窗口的背景画本身没有修改。

身份参考背景源于此前以 HoYoWiki 官方头像为参考的同人创作，原图来源与角色权利说明见 [第三方声明](../THIRD_PARTY.md)。这是非官方同人图，不代表 miHoYo / HoYoverse 的认可。
