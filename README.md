# EnglishAssistant

<img src="resources/vodyanitsa.png" width="72" alt="沃雅妮莎头像" />

仅支持 Windows x64 的离线英文候选助手，搭配微软拼音。在中文候选旁显示英文单词或短句，按住 **Ctrl** 用数字或方向键选择，松开输出英文。

## 使用

1. 在 GitHub 点击 **Code → Download ZIP**，下载完整仓库并解压。
2. 双击根目录 **EnglishAssistant.exe**，托盘出现沃雅妮莎头像。
3. 切到微软拼音中文模式，输入拼音，先不要提交中文。
4. 查看英文面板的编号，按住 **Ctrl**，按数字选择，松开 Ctrl 输出。按住期间可换选，无需 Shift。

也可以按住 **Ctrl**，用 **↑ / ←** 选择上一条、**↓ / →** 选择下一条，松开 Ctrl 输出。首次按方向键选中当前页第一条，继续按可跨页选择；到首尾时停止。也可点击英文条目。数字以英文面板当前编号为准。

同一中文候选的英文释义放在一组横向排列，例如“发展”对应 1 develop、2 development、3 growth；每条保留独立编号。面板根据当前应用窗口、中文候选区域和屏幕可用宽度调整，放不下时在同组内换行。

英文面板优先放在中文候选上方，预留拼音行与间距；空间不足时减少每页条目，自动分页，靠近屏幕顶端时改放下方。

右键托盘可暂停、设置**开机自启动**、打开**英文 → 中文翻译框**、**翻译框背景…**、**英文选词框背景…**或退出。使用说明与两个个人词表菜单已移除。

详细操作见 [使用说明](使用说明.md)。可以移动整个文件夹；保留 exe、data、models、runtime、translation、resources 与许可文件。首次启动自动创建 personal.tsv；升级不会覆盖已有词表。模型权重约 80 MB，Windows 翻译运行库压缩约 60 MB，初次翻译自动解压；只运行英文候选时不加载模型。

## 离线词库与整句

从青简仓库克隆、筛选后，内置 **232,202 条中英词条、44,190 条英中词条**，另有人工整理的日常与软件短句、名词补充及有限表达模板。筛选分类和来源版本见 [data/LIBRARY.md](data/LIBRARY.md)。

查询顺序：个人词表 → 本地短句 → 自带词库合并补充 → 完整槽位匹配的表达模板。较完整的候选译文优先排列，例如“托盘中增加一个选项”首先显示 **Add an option to the system tray.**，可用 Ctrl＋1 输出。

例如“发展”显示 develop、development、growth，保留动词并补充名词。data/supplements.tsv 收录人工整理的常见词补充，与原词库合并并去重；尚未覆盖所有词的词性。可用个人词表指定自己的释义和顺序。

运行时完全离线，不发送输入、不调用翻译 API，没有额度或次数限制。整句未命中时，按已知词组进行动态规划分词并查词，优先完整覆盖和较长词组，结果排在较短中文候选之前，并标为 **词组参考**。未收录片段显示 `[untranslated: 原文]`，不会悄悄丢掉。截图中的“趋于完美了”对应 **It is approaching perfection.**；其他未收录组合也会调用词库，不必先逐条添加整句。

词库匹配不具备通用翻译模型的语法与上下文能力，词组参考可能不通顺或选错义；可用个人词表覆盖常用整句。打字候选只处理输入法当前提供的、尚未提交的中文，不读取之前已发送的段落。

## 英文转中文翻译框

右键托盘 → **英文 → 中文翻译框**，在上框粘贴英文，点击“翻译为中文”或按 Ctrl＋Enter，下框显示中文。优先精确本地词条；其他英文句子和段落使用 **OPUS 英中本地神经翻译模型**，不再将单词释义拼接成译文。截图示例 `Stateless GitHub App installation tokens rolled out` → **无状态 GitHub App 安装令牌已推出**。模型按句处理、保留段落，每次最多 8000 字符，过长文本请分段。

推理完全在本机 CPU 运行，不调用联网服务，没有额度限制。首次使用可能稍慢；关闭窗口会取消任务并回收翻译进程。支持选中结果后 Ctrl＋C；不自动读取剪贴板，不保存粘贴历史。机器翻译仍可能误译或遗漏细节，请核对专名和专业内容。模型来源与完整许可见 [models/README.md](models/README.md)。

## 自定义背景

托盘的 **翻译框背景…** 和 **英文选词框背景…** 分别设置两种窗口。点击“选择图片 / 视频”，或者把文件拖入设置窗口。支持 PNG、JPG、BMP、GIF 动图，以及系统可解码的 MP4、WMV、MOV、AVI 视频；优先使用 H.264 MP4。可在设置中勾选“播放视频声音”，默认静音，预览始终静音。窗口隐藏时停止刷新并暂停声音；“恢复默认背景”可随时还原。

默认提供沃雅妮莎主题的 **月下水庭**（翻译框）与 **晨光涟漪**（英文选词框），为两张不同的静态图片，采用浅色卡片保证文字可读。使用 Codex 内置图像工具生成，设计提示见 [resources/backgrounds/PROMPTS.md](resources/backgrounds/PROMPTS.md)。自定义媒体保存在 `backgrounds/custom`，不提交到仓库。图片最大 8192×8192、视频最大 4096×4096；推荐 1080p 或以下。

## 开机自启动

右键托盘勾选“开机自启动”，在当前 Windows 用户登录后启动；再次点击取消。首次使用默认关闭，无需管理员权限。移动整个目录后手动运行一次，会更新已启用的启动路径；不要只移动 exe。

## 构建

程序和词库核心使用 C++17，界面使用原生 Win32、GDI+、Media Foundation。构建需要 CMake 3.20+、Ninja、MinGW-w64 GCC；内置独立 Python 3.12 运行库只用于整句翻译，无需额外安装 Python、浏览器或 .NET 服务。

```powershell
.\EnglishAssistant.exe --quit
.\build.ps1
```

可传 `-ToolchainBin '工具链bin目录'`。脚本在 work/build 构建并运行 CTest，通过后更新根目录 exe，保留个人设置。移动项目后会归档旧 CMake 缓存并重新构建。

UIA 候选读取和翻译框查词在线程中运行，键盘回调只检查已准备的编号。输出前重新核对焦点和候选，取消拼音并确认候选消失，再输入 Unicode。

源码在 src，图标在 resources，验证工具在 tests，词库导入工具在 tools。普通使用不记录输入历史；候选输出不用剪贴板，自启动由用户选择。个人词表、配置、备份与构建缓存不提交到 Git。

已执行双向词库、名词补充、整句排序、离线模板、未收录标记、自启动注册表开关、编号、方向键选择、窗口避让和内置文本读写检查，并检查原生界面。微软拼音在不同应用中的 Ctrl 选词、连续换选、鼠标输出和多屏交互仍需要实测；未来 Windows 更新、旧版 IME 和管理员程序可能需要适配。
