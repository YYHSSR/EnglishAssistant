# EnglishAssistant

<img src="resources/vodyanitsa.png" width="72" alt="沃雅妮莎头像" />

Windows 微软拼音英文候选助手。继续使用微软自带输入法，在中文候选旁显示英文单词或短句，按 **Ctrl＋数字** 输出英文。

## 使用

1. 在 GitHub 点击 **Code → Download ZIP**，下载完整仓库并解压。
2. 双击根目录 **EnglishAssistant.exe**，托盘出现沃雅妮莎头像。
3. 切到微软拼音中文模式，输入拼音，先不要提交中文。
4. 查看英文面板的编号，按住 **Ctrl**，按数字选择，松开 Ctrl 输出。按住期间可换选，无需 Shift。

多页释义用 **Ctrl＋← / →** 翻页，也可点击英文条目。以英文面板当前编号为准。

右键托盘可暂停、开启免费联网补充、编辑个人词表、重新加载词表、打开使用说明或退出。编辑词表和使用说明均为**内置原生窗口**，不依赖系统记事本。

详细操作见 [使用说明](使用说明.md)。可以移动整个文件夹；保留 exe、data、personal.example.tsv、说明与许可文件。首次启动自动创建 personal.tsv；升级不会覆盖已有词表。

## 本地与联网

包含 232,213 条青简英文词条及常用短句。查询顺序：个人词表 → 本地短句 → 自带词库 → 可选 MyMemory 补充。

联网默认关闭。开启后，输入稳定约 0.8 秒时，只发送本地未收录的候选短句给 MyMemory，不发送整段文档或已输入上下文。匿名服务通常每天提供 5,000 字符，本程序限制为最多 4,000 字符，不配置付费密钥、不购买额度。断网或超限时继续使用本地内容。

## 构建

C++17、原生 Win32、Windows x64；CMake 3.20+、Ninja、MinGW-w64 GCC。不需要 Python、浏览器或 .NET 服务。

```powershell
.\EnglishAssistant.exe --quit
.\build.ps1
```

可传 `-ToolchainBin '工具链bin目录'`。脚本在 work/build 构建并运行 CTest，通过后更新根目录 exe，保留个人设置。移动项目后会归档旧 CMake 缓存并重新构建。

UIA 和 HTTP 各自在线程中运行，键盘回调只检查已准备的编号。输出前重新核对焦点和候选，取消拼音并确认候选消失，再输入 Unicode。

源码在 src，图标在 resources，验证工具在 tests。普通使用不记录输入历史、不用剪贴板、不设自启动。个人词表、配置、用量记录、备份与构建缓存不提交到 Git。
